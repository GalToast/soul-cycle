# Soul Cycle Assets

## Audio

The MP3 files in `assets/music/` are original AI-generated soundtrack assets created by Fred McCullough for Soul Cycle.

They are included for playback in the game and soundtrack browser. They are not covered by the repository's MIT source-code license unless a future asset license states otherwise.
