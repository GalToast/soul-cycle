# Soul Cycle

A procedural life simulation where you live, die, and return — carrying fragments of experience across incarnations.

**Play now:** https://[username].github.io/[repo]/

## How to Play
1. Open index.html in a browser
2. Click NEW LIFE to begin
3. Read events, make crisis decisions (A/B/C), respond to fragment whispers (Y/N)
4. Watch the J-curve animate as your life unfolds
5. When you die, read your eulogy and see what fragments you collected
6. Click NEW LIFE to begin again — your soul carries fragments forward

See QUICKSTART.txt for full mechanics guide.

## Technical
- Single HTML file, no dependencies
- Vanilla JS, CSS animations
- Web Audio API for procedural sound
- Canvas API for J-curve visualization
